# The AI Engineering Skills Map — Andrew Ng

> [!tldr] Andrew Ng presents four practical areas of AI-engineering skill: building AI applications, software-engineering fundamentals, using coding agents, and shaping what gets built.

## Overview

Andrew Ng’s X post announces “a map of the most important skills in AI Engineering.” The visible post frames AI engineering as a broad capability set for developers and employers, not merely a job title. The linked X article was not retrievable during ingest because it returned 404/login-gated content, so this page records the framework visible in the post and its accessible page metadata rather than reconstructing unavailable detail. ^[ambiguous]

The map connects technical execution with judgment: engineers must build and evaluate probabilistic AI systems, retain strong software fundamentals, use coding agents effectively, and make product and business decisions about what should be built.

## Key Points

- **Build and deploy AI applications.** AI application work requires evaluation, measurement, error analysis, and governance because outputs are less predictable than conventional deterministic software.
- **Keep software-engineering fundamentals.** Architecture, security, scalability, maintainability, and cost trade-offs remain important even when AI systems generate much of the implementation.
- **Use coding agents well.** The skill is broader than prompting: it includes context management, planning, specification, orchestration, verification, and safe deployment practices. ^[inferred]
- **Shape the build.** Product judgment, business understanding, and ownership of the resulting user experience increasingly matter alongside implementation skill. ^[inferred]
- **Keep learning.** AI tools and development practices change quickly, so continuous learning is part of the capability rather than a one-time prerequisite. ^[inferred]
