# Google Agents Course: Agents → Tools → Loops → Graphs → Autonomous Systems

> **Source:** [Hanako's X post](https://x.com/i/status/2083932817738666010), retrieved through a Nitter mirror because direct X retrieval was blocked. The post embeds the full course recording and quotes her own [Eval Engineering article](https://nitter.tiekoetter.com/i/article/2083540339147567268). ^[extracted]

## What the Post Says

Hanako recommends a free Google course that covers the full progression in one place: agents → tools → loops → graphs → autonomous systems. She frames the progression as the point — "one agent is a demo, an agent with tools does work; loops let it keep going; graphs let several of them coordinate; only the last step runs without you in the room" — and notes most people stop after step one, still tuning the prompt. ^[extracted]
