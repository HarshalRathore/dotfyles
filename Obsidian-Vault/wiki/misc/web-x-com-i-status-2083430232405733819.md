# Google I/O Keynote: Antigravity and Agent-First Development

## World Models and Media Provenance

A Google DeepMind segment presents **world models** as a move from predicting text toward simulating reality. It combines Gemini's reasoning with generative media systems for videos, images, and interactive simulations, and introduces the Omni family as a more capable route toward intuitive-physics-like behavior. The first announced model is Gemini OmniFlash; the transcript renders several model names imperfectly, so product-name details beyond that label remain source-bound. ^[extracted] ^[ambiguous]

The keynote says SynthID has watermarked more than 100 billion images and videos and 60,000 years of audio. It also describes expanding provenance checks into Search and Chrome and names OpenAI, Kakao, and Levin Labs as adopting SynthID. ^[extracted]

## Gemini 3.5 Flash and the Agent-First Stack

The keynote introduces **Gemini 3.5 Flash** as a model combining frontier intelligence with action. It claims broad benchmark gains over Gemini 3.1 Pro, roughly four-times-higher output-token speed than other frontier models, and internal usage growing from about 0.5 trillion to more than 3 trillion tokens per day. The benchmark chart and exact comparison are announcement claims, not independently reproduced here. ^[extracted] ^[ambiguous]

The surrounding product is **Google Antigravity**. The announcement lists:

- a full CLI;
- an Antigravity SDK;
- native voice support using Gemini audio models;
- integrations with Android, Firebase, and Google AI Studio; and
- Antigravity 2.0, a standalone desktop surface centered on agent conversations, generated artifacts, and multi-agent orchestration. ^[extracted]

The Antigravity harness is described as adding sub-agents, hooks, and asynchronous task management. Gemini 3.5 Flash is presented as co-optimized with that harness, making the product claim about the model-and-runtime pair rather than the model in isolation. ^[extracted]

## Parallel Operating-System Demonstration

The keynote describes an experiment in which Antigravity decomposed an operating-system build, dispatched parallel sub-agents, generated and ran tests, and iterated asynchronously. The stated run lasted more than 12 hours and involved 93 sub-agents, more than 15,000 model requests, and 2.6 billion tokens. The speaker says the result reached a functioning core operating system for under $1,000 in API credits. ^[extracted]

The demo names a scheduler, memory management, and file system among the generated components. It shows the resulting shell running `sl`, then uses Antigravity to address missing video and keyboard drivers after Doom fails to launch. This is a product demonstration and self-reported experiment, not an independently verified operating-system benchmark. ^[inferred]

The desktop tour emphasizes a second artifact surface: an earlier research conversation produced plots, an infographic, and graphs generated from code. The human can inspect those artifacts while the agent continues work, which makes the UI an orchestration and review surface rather than only an editor. ^[extracted]

## Distilled Implications

1. **Agent-first development is a surface decision.** The announced product puts conversations, artifacts, asynchronous execution, and multi-agent coordination beside code rather than treating an agent as autocomplete inside an IDE. ^[inferred]
2. **Parallelism changes the unit of work.** A long-running task becomes a managed team of sub-agents with shared objectives, generated tests, and a reviewable artifact. ^[inferred]
3. **Harness design is part of model capability.** Hooks, task management, tools, and artifact handling are presented as co-equal with Gemini's raw reasoning and speed. ^[inferred]
4. **Throughput requires verification.** The OS experiment's stated success depends on generated tests and iteration; the live demo still exposes missing drivers, so a large agent run is not evidence that every subsystem is correct. ^[inferred]
