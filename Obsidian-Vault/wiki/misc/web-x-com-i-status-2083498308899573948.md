## What the Captured Lecture Actually Covers

1. **Tokenization (`00:00–00:10`)** — Text is mapped to IDs from a learned subword vocabulary. Subword units let the model reuse representations across related or rare words; the lecture names byte-pair encoding (BPE) as a vocabulary-building/tokenization method. ^[extracted]
2. **Autoregressive factorization (`00:10–00:25`)** — A sequence distribution is decomposed with the chain rule into conditional next-token distributions, each represented by logits followed by a vocabulary-sized softmax. Token IDs are first mapped through a learned embedding matrix. ^[extracted]
3. **Generation and sampling (`00:25–00:38`)** — Generation feeds each sampled token back into the model. Temperature rescales logits: lower values sharpen the distribution and higher values increase diversity. Top-k sampling keeps only the highest-logit candidates before renormalizing. ^[extracted]
4. **Transformer structure (`00:38–00:42`)** — The model alternates attention over a sequence with position-wise multilayer perceptrons. Attention is the cross-position operation; the MLP processes each position independently and can run in parallel across positions. ^[extracted]
5. **Scaled dot-product attention (`00:42–01:05`)** — Query, key, and value projections produce attention weights from query–key inner products, followed by a row-wise softmax and a weighted sum of values. A causal mask adds negative infinity above the diagonal so a position cannot read future tokens. ^[extracted]
6. **Multi-head attention (`01:05–01:16`)** — Several attention heads use different projection matrices, concatenate their outputs, and apply a final projection. The attention score matrix has quadratic sequence-length cost, motivating memory-efficient variants such as FlashAttention. ^[extracted]

## Distilled Implications

- **The model is a conditional distribution, not a word lookup.** The chain-rule view makes next-token prediction precise: each position emits a probability distribution conditioned on earlier positions. ^[inferred]
- **Causality is enforced in the computation graph.** The upper-triangular attention mask is what keeps training-time parallel computation consistent with left-to-right generation. ^[inferred]
- **The expensive part scales with context length.** The `T × T` attention score matrix makes long contexts costly even when the parameter count is independent of sequence length. ^[inferred]
- **Sampling knobs trade determinism for diversity.** Temperature and top-k alter decoding behavior without changing the trained model weights. ^[inferred]
