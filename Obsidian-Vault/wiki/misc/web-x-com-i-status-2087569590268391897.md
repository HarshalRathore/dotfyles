## The Article

Deep dive: [[references/show-me-compact-visual-representations|show-me: compact visual representations for coding agents]].

Core claims:
- Coding agents are "pretty much unreadable": RL-trained models increasingly answer in walls of jargon that glaze eyes over; builders (a former Reddit CEO, Mario Zechner of pi, Connor of Replicas, Dillon Mulroy) push back with simplify-the-language skills. ^[extracted]
- The proposal: a **show-me** skill (published as `humanlayer/skills`) that prompts agents to explain with concise visuals — component trees, call stacks, diagrams, file layouts, pseudocode, types/signatures, diff syntax, HTML mockups — instead of prose. ^[extracted]
- "Lighter and faster than HTML, good enough for most dev-work shaped problems" — compact visuals sit below full HTML in the agent-output toolkit. ^[extracted]
- Best uses: program design (discussing the shape of the code — types, signatures, call stacks — before agents write it) and post-hoc exploration of large diffs. ^[extracted]
- Install: `npx skills add humanlayer/skills --skill show-me` (or `brew tap humanlayer/humanlayer && brew install humanlayer`); HumanLayer's hosted product renders inline HTML and diagrams first-class. ^[extracted]
