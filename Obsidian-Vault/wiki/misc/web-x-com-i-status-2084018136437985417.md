# LazyGraphRAG vs Million-Token Context + How to be a Memory Engineer

> **Source:** [N01ennn's X post](https://x.com/i/status/2084018136437985417), retrieved through a Nitter mirror. The post embeds a 14:48 talk clip and quotes his own [How to be a Memory Engineer](https://nitter.tiekoetter.com/i/article/2083971749079581120) article. ^[extracted]

## What the Post Says

N01ennn reports that Microsoft ran its graph system against vector RAG on 8k, 120k, and a full million-token context window, and the million-token run lost: LazyGraphRAG won 92, 90, and 91 percent of data-local questions — "the exact place plain RAG was supposed to be strong" — at a tenth of the cost of the million-token run. His takeaway: "a bigger context window is not memory, structured memory is." ^[extracted]

## Source and Media Check

The embedded MP4 measures 888.064 seconds (14:48.064). It is the **AI Engineer World's Fair 2025 talk by [[entities/jonathan-larson|Jonathan Larson]]** (GraphRAG lead, Microsoft Research) — the same talk already ingested from YouTube at [[references/aief2025-graphrag-code-jonathan-larson]]. Remote ASR (15 bounded chunks, no silent gaps) confirms every claim in the post: the 92/90/91% data-local win rates against the 8k/120k/1M vector-RAG baselines, the finding that the long context window did not help on global questions, and the 1/10th cost versus the million-token run. ^[extracted]

The transcript also adds detail the existing reference page lacked: Benchmark QED's components (AutoQ query generation across a local/global × data-driven/activity-driven spectrum, AutoE LLM-as-judge evaluation, AutoD summarization and sampling) and a closing demonstration of graph-based scientific co-reasoning powered by GraphRAG/LazyGraphRAG. ^[extracted]

One reply notes LazyGraphRAG dates from 2024 and the talk from 2025; the talk itself references a November blog post about it. ^[ambiguous]

## Quoted Article

The post quotes N01ennn's own X article, **How to be a Memory Engineer, from the perspective of Stanford, Microsoft, Anthropic and Nvidia** — fifteen steps across six themes arguing the job is engineering *forgetting*, not remembering.
