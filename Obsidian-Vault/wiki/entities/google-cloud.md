# Google Cloud

Google Cloud is Google's cloud platform — including Cloud Run (serverless containers), BigQuery, Cloud Shell, and the AI platform services used by Google's agent workshops. The Space Quest Omni App workshop deploys its MCP servers, multi-agent system, and live multimodal agent to Cloud Run. ^[extracted]
