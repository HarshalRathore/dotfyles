# Ahmad Awais

**Ahmad Awais** (@MrAhmadAwais) is the CEO of **Command Code AI** (⌘ @CommandCodeAI), founder of Langbase, former VP of Developer Experience, member of the Google Developer Advisory Board, an award-winning GitHub Star, and a developer whose code has flown on NASA Mars missions. He is based in San Francisco, CA. ^[extracted]

## Role

- **CEO, Command Code AI** — the coding-agent harness (⌘ Command Code) purpose-built for open models; drives its harness-engineering work (see [[references/command-code-read-tool-harness-engineering|The Read Tool deep dive]]). ^[extracted]
- **Founder, Langbase** — a serverless AI platform (per his bio). ^[extracted]
- **Ex VP DX**, Google Developer Advisory Board, GitHub Star; praised by Satya Nadella as an "awesome example for devs". ^[extracted]

## Notable Public Positions (as captured in the wiki)

- Tool-calling failures from open models are **repair problems, not capability gaps** — a small targeted repair layer (30–100 lines) fixes ~90% of failures (DeepSeek, Qwen, GLM). See [[concepts/tool-input-repair-layer|Tool-Input Repair Layer]]. ^[extracted]
- Open-model constraint is a feature: it forces harness engineering because a wasted turn shows in the eval score the same day. ^[extracted]
- Harness selection by "random vibe" is broken — "minimal" or "from the model maker" does not mean best-engineered. ^[extracted]
